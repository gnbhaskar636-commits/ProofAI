# ProofAI — 2-minute demo

Closing line: “AI systems change. Proof should not.”

## 0:00 Overview

Open the console.

> “This is ProofAI. We still seal configuration changes with CooL. On top of that we add change intelligence, a live system twin, and an evidence copilot. Analysis is not proof.”

Show Customer Support AI: model, prompt, policy, tools, deployment.

## 0:20 Seal

Create change. If the live system is Model-B / v13, set After to Model-C / v14. On a fresh store, first seal Model-A → Model-B / v13, then Model-C / v14.

Click **Seal Change with CooL**.

> “That is the real CooL SDK. We now have a receipt, not a log line.”

## 0:40 Analyze

Click **Analyze Change**.

> “Risk is MEDIUM because the model and prompt both moved. This is AI-generated analysis — not a safety certification and not the CooL verdict.”

## 0:55 Twin

Open **AI System Twin**. Click Model and Prompt.

> “Those nodes glow because they changed. Click a node for current/previous config, evidence ID, timestamp, verification, and the risk note.”

## 1:10 Verify + tamper

Back on the receipt: **Verify Evidence** → VERIFIED.

**Tamper Test**, then **Verify tampered copy** → VERIFICATION FAILED.

> “The original still verifies. We never destroy the sealed receipt.”

## 1:30 Copilot

Open **AI Copilot**. Ask: “What changed in the latest deployment?”

> “The answer cites the real evidence ID from the store.”

## 1:50 Close

> “ProofAI does not make you EU AI Act compliant and does not prove the model is correct. It does one job: when AI systems change, the proof should not.”
